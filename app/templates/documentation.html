OVERVIEW

Language Identification API

LangDetectAI exposes a REST API that accepts text and predicts the language represented by that text.

The API is built using FastAPI and uses a trained character-level LSTM neural network for classification.

API Version v1
BASE URL

API Base URL

During local development, the API is available through the following address:

Local 
http://127.0.0.1:8000
ENDPOINTS

Available Endpoints

Method Endpoint Purpose
GET / Home page
GET /api/v1/health API health status
GET /api/v1/languages Supported languages
GET /api/v1/model-info Model information
POST /api/v1/predict Predict language
POST /api/v1/predict

Prediction API

Send a piece of text to the prediction endpoint to identify its language.

Request

JSON 
{
    "text": "Bonjour, comment allez-vous aujourd’hui ?"
}

HTTP Request

HTTP 
POST /api/v1/predict
Content-Type: application/json
RESPONSE

Prediction Response

A successful prediction returns the detected language and the model's confidence value.

JSON 
{
    "language": "French",
    "confidence": 0.9997
}
language string

Predicted language name.

confidence float

Predicted probability returned by the classification model.

VALIDATION

Request Validation

Incoming requests are validated using Pydantic before reaching the prediction service.

Required The text field must be provided.
Minimum Length At least 1 character.
Maximum Length Maximum 5,000 characters.
Whitespace Text containing only whitespace is rejected.
PREDICTION PIPELINE

How a Prediction Works

01
Receive Text

FastAPI receives and validates the JSON request.

02
Preprocess

Emojis are removed and the text is converted into character sequences.

03
Pad Sequence

The sequence is padded or truncated to 650 characters.

04
LSTM Prediction

The trained neural network generates probabilities for the ten language classes.

05
Return Result

The highest-probability class is converted to its language name and returned as JSON.

MODEL

Model Architecture

Input 650 characters
↓
Embedding 64 dimensions
↓
LSTM 128 units
↓
Dense 64 units
↓
Softmax 10 classes
ERRORS

Error Handling

Invalid requests are rejected before reaching the model.

422 Validation Error 
{
    "detail": [
        {
            "type": "string_too_short",
            "loc": ["body", "text"],
            "msg": "String should have at least 1 character"
        }
    ]
}
LOCAL DEVELOPMENT

Run the Project Locally

Start the FastAPI application from the project root directory.

Terminal 
uvicorn app.main:app --reload

Once the server starts, open the application in your browser.

Browser 
http://127.0.0.1:8000
